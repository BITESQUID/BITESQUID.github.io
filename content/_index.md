## Launcher & Mod Loader
BITESQUID is a runtime multi mod loader built for Bitsquid / Autodesk Stingray engine games but may also include other games if relatable. It does not modify or redistribute original game files.

## Modding framework
BITESQUID provides the LUA framework and mods are open to the community. The loader portion of the code is currently closed. The end goal is to open more of the project over time. This is a passion driven project and sometimes developers choose to keep certain components closed so they can learn, iterate, and maintain a consistent direction without the project being immediately forked or repackaged by others. Closed source does not imply suspicious behavior. Many software tools people use daily are closed source. What matters is transparency and documentation, not whether every line of code is public.

## Mod Config Schema
BITESQUID provides mod config settings if mod authors choose to implement them. This allows players to fully customize their modding experience.

## Community Bans
BITESQUID includes a cross-game banlist to protect the community across all supported titles.

The banlist is fully editable by anyone, but the version shipped with BITESQUID reflects our stance and is intended to keep the wider community safe.
